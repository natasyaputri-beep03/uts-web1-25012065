## Deskripsi

Aplikasi pemesanan makanan dan minuman kantin kampus menggunakan PHP Native. Aplikasi menyediakan pencarian menu, pemesanan, keranjang belanja, perhitungan subtotal, dan diskon.

## Fitur

* Menampilkan daftar menu makanan dan minuman.
* Mencari menu menggunakan GET.
* Memproses pesanan menggunakan POST.
* Memvalidasi kode menu dan jumlah pesanan.
* Menyimpan keranjang menggunakan session.
* Menghitung subtotal, diskon 10%, dan total pembayaran.
* Menghapus item dan mengosongkan keranjang.

## Persyaratan

* PHP versi 7 atau lebih baru.
* Browser web.

## Cara Menjalankan

1. Buka terminal pada folder proyek.

2. Jalankan server PHP menggunakan perintah:

   `"/c/xampp1/php/php.exe" -S localhost:8000`

3. Buka browser dan kunjungi `http://localhost:8000`.

## Catatan

Aplikasi menggunakan PHP Native tanpa framework dan database.
